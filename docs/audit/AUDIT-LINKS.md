## 5. Проблемы по важности

### 5.1 Битые — ведут в 404

**Переключатель языков на страницах категорий блога.** Он строит адрес как «префикс локали + оставшийся путь», а слаги категорий локализованы (`tsykly` / `tsikly` / `cycles` / `cykle` / `zyklen`). Слаг не переводится → 404.

Проверено все 60 переходов (3 категории × 5 локалей × 4 языка): **битых 58, рабочих 2** (только uk ↔ ru для «Техніки», где слаг совпадает — `tehnika`). Это 55 уникальных 404-адресов; на полном обходе 80 страниц и 166 внутренних адресов **все остальные внутренние ссылки отвечают 200**.

```
/uk/blog/tsykly            → /ru,/en,/pl,/de/blog/tsykly            — 4× 404
/uk/blog/kolektsionuvannia → /ru,/en,/pl,/de/blog/kolektsionuvannia — 4× 404
/de/blog/zyklen            → /uk,/ru,/en,/pl/blog/zyklen            — 4× 404
…и так для всех 15 страниц категорий
```

При этом `generateMetadata` для тех же страниц собирает `localizedPaths` с правильными локализованными слагами — hreflang в `<head>` корректный, видимый переключатель в шапке — нет.

**Страница 404 — тупик.** `not-found.js` в проекте нет. Отдаётся встроенная страница Next.js: «404 | This page could not be found» по-английски независимо от локали, **без шапки, без футера, 0 ссылок** — вернуться можно только кнопкой «Назад» браузера.

### 5.3 Мёртвые

- **Логотип в мобильном меню** — `<span class="logo">`, не ссылка. `cursor: pointer` не задан, но `.logo:hover` меняет цвет: элемент реагирует на наведение и не реагирует на клик.
- **`<button class="btn-secondary">` без `onClick`** в `AuthenticitySection.js:44` — ветка на случай отсутствующего скана сертификата. Сейчас не активна (файл в данных есть), но код в сборке.
- **`RelatedPosts`** — вызывается на каждой статье, всегда получает пустой список и возвращает `null`.
- **`.order-type-card` / `.order-type-cards`** в `app/globals.css:620–640` — стили карточек выбора типа заказа. В JSX этих классов больше нет (остался только скрытый `<input name="orderType">`). Ничего не рендерится.
- Элементов `span`/`div` с `cursor: pointer` **без** обработчика на сайте нет — единственные такие `.thumb` и его дети, обработчик есть.

### 5.4 Технические огрехи

- **Instagram в мобильном меню** (`components/Header.js:106`) — внешняя ссылка без `target="_blank"` и без `rel`. В футере и на /kontakty у той же ссылки `target="_blank" rel="noopener noreferrer"`.
- **Ссылка на разработчика** — `rel="noopener"` без `noreferrer`, в отличие от остальных внешних.
- **`.thumb` — `<div>` с `onClick`** вместо `<a>`/`<button>`: нет фокуса с клавиатуры, Enter/Space, средней кнопки, контекстного «открыть в новой вкладке».
- **`<button>` без `type`** — бургер, ScrollTop, «Придбати», «показати по одній», навигация просмотрщика, ✕ модалки. По спецификации это `type="submit"`; все они вне `<form>`, поэтому последствий нет. Явный `type="button"` стоит только у `ThemeToggle`.
- **Мобильное меню перекрывает переключатель темы**: `.mobile-menu` — `position: fixed; inset: 0; z-index: 100`, `.header` — `z-index: 50`. Пока меню открыто, кнопка темы недоступна, внутри меню её нет.
- **Мобильное меню не закрывается** ни по Escape, ни по клику вне — только по «Закрити» или по переходу.
- **`proxy.js` не добавляет локаль к `/blog/<slug>`**: matcher исключает `blog/` (`proxy.js:53`). `/blog` → 307 на `/en/blog`, а `/blog/majster-i-margaryta-cykl` → 404 без редиректа. На сайте таких ссылок нет; это касается внешних входящих ссылок на старые адреса.
- **Ссылок без локали в пути на сайте нет**, `href=""` и `href="#"` — нет, якорей на несуществующие элементы — нет.
