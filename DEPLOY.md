# Як викласти сайт на Vercel

Безкоштовного тарифу Hobby вистачає з запасом.

## Варіант 1 — через термінал (найшвидший)

У папці проєкту:

    npx vercel

Перший запуск попросить увійти в акаунт (відкриє браузер).
Далі на всі питання можна тиснути Enter:

    Set up and deploy? — Y
    Which scope? — твій акаунт
    Link to existing project? — N
    Project name? — iwan-kulik
    In which directory is your code? — ./
    Modify settings? — N

Отримаєш адресу виду `iwan-kulik-xxx.netlify.app`.

Це буде превʼю-версія. Щоб зробити її бойовою:

    npx vercel --prod

## Варіант 2 — через сайт Vercel (без терміналу)

1. Створити репозиторій на GitHub і залити туди папку проєкту
2. vercel.com → Add New → Project → Import з GitHub
3. Framework Next.js визначиться сам, нічого не змінювати
4. Deploy

Плюс цього варіанту: кожен `git push` автоматично оновлює сайт.

## Змінна оточення

У Vercel → Project Settings → Environment Variables додати:

    NEXT_PUBLIC_SITE_URL = https://твій-домен.com

Вона потрібна для hreflang, canonical і превʼю посилань у месенджерах.
Поки домену немає — постав адресу, яку видав Vercel.

## Свій домен

Vercel → Project → Settings → Domains → Add.
Vercel покаже, які DNS-записи прописати в реєстратора.
HTTPS-сертифікат випускається автоматично.

## Що перевірити після викладення

- [ ] Відкривається корінь і перекидає на потрібну мову
- [ ] Перемикач мов і темна тема працюють
- [ ] Відео в героєві грає без звуку
- [ ] Форма заявки надсилається (лист поки не приходить — див. нижче)
- [ ] `/sitemap.xml` і `/robots.txt` відкриваються

## Адмінка

Адреса: `/admin`. Вхід за логіном і паролем окремо для кожного
користувача (див. env-змінні нижче).

Налаштування на Vercel (один раз):
1. Project → Storage → Create Database → **Blob** → Create.
   Токен `BLOB_READ_WRITE_TOKEN` пропишеться сам.
2. Згенерувати хеш пароля для кожного користувача:
   `node scripts/hash-password.mjs "пароль"`.
3. Project → Settings → Environment Variables → додати:
   - `ADMIN_USERS` = JSON-масив `[{"login":"...","name":"...","hash":"..."}]`
   - `SESSION_SECRET` = випадковий рядок від 32 символів
     (наприклад, `openssl rand -base64 32`)
4. Передеплоїти: `npx vercel --prod`.

Що вміє: додавати/редагувати/видаляти розписи й картини, міняти
порядок стрілками (нове саме стає нагору), завантажувати фото
(стискаються в браузері до 1920px), редагувати контакти. Зміни
з'являються на сайті одразу, без пересборки.

Переклади в адмінці необов'язкові: якщо поле EN/PL/DE порожнє,
сайт покаже українською, а переклад можна додати пізніше.

На своєму сервері (після переїзду з Vercel) нічого міняти не треба:
без BLOB-токена дані живуть у `content/data.json`, фото —
у `content/uploads/`. Ця папка — і є база сайту, бекапити її.

## Пошта для заявок

`app/api/inquiry/route.js` шле лист на `MAIL_TO_ADMIN` через Resend
(`lib/mail.js`). Потрібні env-змінні:

- `RESEND_API_KEY`
- `MAIL_FROM` — відправник, напр. `noreply@send.iwankulik.com`
- `MAIL_TO_ADMIN` — куди приходять заявки

Без `RESEND_API_KEY` (наприклад, локально) лист просто не шлеться —
у консоль пише warning, заявка все одно логується й сайт не падає.

## Що лишилось доробити

1. Реальна адреса пошти в `data/site.js`.
2. Площі `{…} м²` і роки `{…}` в `data/site.js`.
3. Вичитати польську й німецьку носіями.
